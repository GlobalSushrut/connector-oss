\section{Qualification checklist (3 questions)}

\begin{enumerate}
  \item Is your AI already \textbf{taking actions}, not only producing text?
  \item When it makes the wrong call, can you \textbf{explain why}?
  \item Have you had an incident---or do you \textbf{expect one soon}?
\end{enumerate}

If yes / no / yes $\rightarrow$ prioritize for outreach.
