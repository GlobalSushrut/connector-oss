4. Zero-trust handshake & probabilistic LLM

ZT handshake (blockchain-grade tool binding)

Policy admission is not enough if the model can call MCP/HTTP directly. Connector is the only signer of tool authority. Session key is never given to the LLM.

PropertyHow
Genesis immutabilitySHA-256 genesis + node Ed25519
Session secrecyRederived from node signature of zt-session|handshake_id
Chain continuityEach ticket prev_hash = previous block_hash
Single-useNonce spent; replay denied
Forgery resistanceHMAC-SHA256 MAC + node signature

Env: CONNECTOR_ZT_HANDSHAKE=1 · Module: kernel/zt_handshake.rs · admit_tool_effect on every ToolDispatch

Probabilistic LLM guard

Connector does not treat the model as ready for unaugmented autonomy. Identity, memory, character, knowledge, HITL, and parameters stay Connector-owned.

EventAction
Bypass of Connector rule (forged ticket, in-process path, exclusivity skip)Quarantine → human retrieval (unquarantine HITL)
Failure of identity / memory / character / knowledge / HITL / parametersMandatory human approval

Env: CONNECTOR_LLM_DISTRUST=1 · Module: substrate/probabilistic_llm.rs · Status: GET …/probabilistic-llm/status

Pair the runtime membrane with docker_lab / microVM so guests physically cannot open sockets around Connector.

Real limitations (do not overclaim)

  • Membrane ≠ full OS syscall proof until H2/H5 pass on the target host
  • LLM forward-pass still runs in connector-platform (distrusted)
  • Remote MCP ignoring ZT needs network isolation
  • MicroVM needs operator-supplied measured kernel/rootfs
  • eBPF is a real loader — attach still requires CAP_BPF / bpffs
  • CONP lab HAL is echo (SIL is partner) · CNP ENABLE is not a live event bus
  • Break-glass flags weaken the claim · court binder refuses military overclaim

The LLM is never: root of identity · signer of tool authority · issuer of world grants · judge of quarantine · source of secrets.

Closing claim

Connector OS is an installable governance node. Under production / defense-strict / unbypassable hardening it closes alternate effect paths, distrusts the probabilistic model, projects policy to Linux (systemd/nft/eBPF connect4 + mark-deny), redirects egress into a Connector proxy hop, and pushes tool/physical I/O into microVM channels with vsock tickets and partner HAL wire adapters. It claims GOVERNANCE and HOST_LAB when evidence is green. It does not claim MILITARY_COURT without signed attach evidence, SIL robotics certification, live CNP bus, or model autonomy.
